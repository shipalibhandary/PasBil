# PassBill – Pastry Billing System
A full-stack pastry billing system built to simplify billing and order management for pastry shops. The application provides a responsive interface for managing products, creating bills, and storing billing-related data using a React frontend, Node.js backend, and MySQL database.

## 🚀 Features
- Manage pastry and bakery products
- Create and manage customer bills
- Calculate item prices and total amounts
- Manage product and order information
- Store data securely in a MySQL database
- REST API integration between frontend and backend
- Responsive and user-friendly interface
- Fast development setup using React and Vite
